## 🚀 Как запустить локально

Так как проект полностью статический (чистый HTML/CSS/JS без бэкенда), достаточно:
1. Кликнуть дважды по файлу `index.html` и открыть его в любом современном браузере.
2. Либо запустить любой локальный статический сервер, например:
   ```bash
   npx serve .
   # или
   python -m http.server 8000
   ```

## ➕ Добавление новых дисциплин и лабораторных (инструкция)

### 1. Добавление новой дисциплины
1. Создайте в корне репозитория папку предмета (например, `BD/`).
2. Скопируйте файл `index.html` из папки `IiVD/` в новую папку `BD/index.html` и настройте название дисциплины и список работ в массиве `LABS`.
3. В корневом файле [index.html](file:///C:/Users/Karasu322/Desktop/labs-mag-sem-1/index.html) добавьте запись в массив `SUBJECTS_DATA`:
   ```javascript
   {
     id: "BD",
     folder: "BD",
     name: "Базы данных",
     code: "БД",
     description: "Проектирование реляционных баз данных и оптимизация запросов.",
     icon: "database",
     link: "BD/index.html",
     labsCount: 1
   }
   ```

### 2. Добавление новой лабораторной работы внутри дисциплины
1. В папке предмета (например, `IiVD/`) создайте подпапку с работой: `LR2/index.html`.
2. В файле страницы дисциплины (например, `IiVD/index.html`) добавьте объект в массив `LABS`:
   ```javascript
   {
     num: 2,
     title: "Лабораторная работа №2",
     subtitle: "Тема и описание лабораторной работы",
     path: "LR2/index.html",
     status: "done", // "done" | "in-progress" | "planned"
     tags: ["Chart.js", "Анализ"]
   }
   ```
3. В корневом [index.html](file:///C:/Users/Karasu322/Desktop/labs-mag-sem-1/index.html) увеличьте `labsCount` для этой дисциплины.
